# Installation

LayerForge Canvas is easy to install and works seamlessly with Blender versions 4.5 through 5.2.

**Download the latest LayerForge Canvas .zip file**.
- https://www. ...
- https://www. ...
- https://www. ...
- 
Open Blender and go to Edit → Preferences → Add-ons.

Click Install… and select the downloaded .zip.

Enable the add‑on in the list to activate LayerForge Canvas.

The LayerForge Canvas panel will appear in the 3D Viewport → Sidebar → LayerForge.

You can now start painting, managing layers, and using the advanced merge system directly inside Blender.
