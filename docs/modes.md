Workflow and modes
Modes de travail
Mode 1 — Handpainting 3D
Workflow classique de peinture sur un objet 3D :
·	Sélectionner un objet
·	Cliquer Create Material
·	Le matériau LF est créé
·	Passage automatique en Texture Paint
·	Le shader passe en Emission pour un rendu neutre
·	Le panel LF s’active
Mode 2 — Canvas 2D
Workflow peinture 2D :
·	Sélectionner un objet
·	Cliquer Create Canvas
·	L’objet est masqué ou supprimé
·	Un plane est créé
·	Une caméra 2D est générée
·	Passage automatique en vue caméra
·	Choix de la taille du canvas (vertical/horizontal)
·	Peinture comme dans un logiciel 2D
